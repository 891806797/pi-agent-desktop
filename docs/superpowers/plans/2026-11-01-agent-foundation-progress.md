## 实施调整

- `GET /sessions` 保留 `sessions` 字段，增加 nextCursor、attention、epoch、seq、listVersion 和删除身份；不维持两套目录协议。
- 删除按会话生命周期幂等，不再接收未使用的动作 UUID；恢复 actionId 仍持久化去重。
- SDK 不落空白历史文件，目录暂存空白名称；有历史后以 SDK 为准。`hasHistory` 防止丢失历史时悄悄重建上下文。
- 三标签页实测六条 HTTP/1 SSE 耗尽同源连接，发送请求排队；相同主题改用 SharedWorker 共享连接。不支持时摘要两秒轮询，相同版本不重置分页，删除身份通过快照同步。
- 删除失败保留可见 deleting 状态、原因和重试入口，启动继续清理；真正完成删除与目录版本同事务推进，然后发 removed。
- editor 无法跨进程重建调用栈时明确中断，由工具未知效果核对或恢复说明接管，不留下没有等待方的旧卡片。
- UI 管理复用导航探针和 `browser_acceptance.py`，没有为设计中的文件名再写重复测试。恢复崩溃窗口使用真实 SQLite/SDK JSONL 断点夹具；真实 kill/restart 另覆盖模型失败、权限和 Ask。

## 保留边界

- 单实例；旧网络请求和 Promise 不复活。外部工具效果与本地记录无法跨系统保证恰好一次，未知窗口必须核对。
- 相同主题已共享 SSE；很多不同会话标签页仍受 HTTP/1 同源连接上限影响，本轮未扩大为动态多主题复用协议。

- 任意磁盘扩展、终端组件、全局草稿读写、完整 TUI 分支/导出及友好 Provider 配置仍未纳入。认证保持简单登录/注册，没有扩展为用户管理平台。

## 后续明确需求：登录、选择器与 SQLite 配置

- 无项目的登录用户留在聊天页，通过目录选择创建项目，修复被强制送往设置页的循环。

- 独立评审发现并以实际失败回归修复：失败配置 Promise 阻塞所有后续发送；等待队列 A 成功时忽略后加的 B；创建等待期间新模型被旧快照覆盖；配置等待后离页/换账号仍触发旧创建。发送绑定页面和用户身份，创建前再次校验。

## 模型来源与选择展示

模型仅取每用户 models.json 显式声明，按文件顺序；创建、切换和请求边界共用身份校验，不再让宿主环境激活的模型进入可选列表。保存选择为空或失效时取第一项，配置为空显示“无可用模型”。前端统一显示 provider · modelId，保存配置后立即刷新设置页数量。reasoning 由用户手工声明，思考档位与请求语义沿用 SDK；列表与会话重开读取手工变更并同步活跃模型元数据，不改用户的实际配置文件。

实际失败回归证明原实现会多出两个环境 DeepSeek 模型；修复后只列 JSON 中模型。另验证默认首项、拒绝配置外切换、手改 reasoning 后读取与重新选择档位、移除或损坏配置后本机 Provider 零请求。后端全量 147 项、前端 48 项通过；类型检查、Lint、Vite、Windows 编译及编译版浏览器验收通过。实际 3001 设置页显示 2，聊天默认显示 ali · deepseek-v4.1-flash，下拉含 ali · glm-5.3-flash。

独立审查实测压缩通过 SDK 的另一条调用路径绕过普通请求事件；补充 `session_before_compact` 校验，同一声明检查覆盖手动及自动压缩。实际 RED：删除配置后压缩仍成功并调用本机 Provider；修复后删除、损坏两种配置均取消压缩且零请求，独立复核确认关闭。

用户随后授权真实调用。使用临时模型能力声明、保持用户 models.json 不变，按 SDK 原生语义验证：DeepSeek 关闭时请求 `thinking.type=disabled`、无思考内容，开启时 `enabled` 并返回思考，两次均正常返回 OK；GLM 的开启/关闭请求均返回 403 Model access denied，需要检查接口侧模型可用性或授权。关闭档位由 Agent 原生转换为 reasoning=undefined，交由对应 SDK 协议发送关闭参数。

## 界面设置与流式交互

聊天顶部改为直角；每次响应用量展示输入、输出、缓存命中率及北京时间。增加独立侧栏拖拽轴、上下限、键盘操作、双击复位与宽度记忆。Provider JSON 编辑改为分块表单，支持连接、模型、思考档位和默认值，原生未展示字段保留。

新增护眼/明亮/暗黑三色调，参考 DeepSeek Harness 的中性色层级，复用语义色变量覆盖界面与菜单；帮助按钮改为循环切换且图标同步。发送模式复用模型/思考的选择面板，设置页返回上一条路由；项目头像背景和边框统一到同一个圆角容器，消除方形内层和不等宽边框。

独立评审及失败回归修复了默认强度被 GET 冻结、模型级协议被强制要求 Provider 覆盖、删除已选模型后新强度被失效身份忽略；表单重新勾选强度时保留已有协议映射值。新增 API 在途合并、账号隔离、写入失效和失败重试验证，已有会话不请求草稿默认值。

旧滚动机制在窗口缩高后无法触底，编译版浏览器先确认失败，再改为内容/视口双观察与按需单帧追踪；真实 SDK 本机 Provider 连续输出验证用户暂停、恢复、输入框和窗口变化。单元验证每帧最多写一次滚动、不在每帧读取内容尺寸、空闲取消、减少动效及资源清理；独立浏览器审查覆盖窗口增高与内容折叠后续写。
